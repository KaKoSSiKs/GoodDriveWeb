# 🔧 Быстрое исправление ошибки 500

## ✅ Таблица создана!

База данных синхронизирована с Prisma схемой через `prisma db push`.

## ⚠️ Осталось сделать:

### 1. Остановите dev сервер
Нажмите `Ctrl+C` в терминале, где запущен `npm run dev`

### 2. Выполните генерацию Prisma Client:

```bash
npx prisma generate
```

### 3. Перезапустите dev сервер:

```bash
npm run dev
```

## ✅ После этого:

1. Форма консультации заработает ✅
2. Запросы будут сохраняться в БД ✅
3. Запросы появятся в админ-панели ✅
4. Ошибка 500 исчезнет ✅

---

**Проблема была:** Prisma Client не знал о новой модели `HelpRequest`, потому что не был сгенерирован после добавления модели в `schema.prisma`.

**Решение:** Выполнить `npx prisma generate` для обновления Prisma Client.
