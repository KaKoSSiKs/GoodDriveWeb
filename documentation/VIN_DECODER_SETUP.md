# 🚗 Настройка декодирования VIN-номера

## ✅ Что реализовано:

### 1. Расширена модель HelpRequest в Prisma schema
Добавлены поля для хранения декодированной информации об автомобиле:
- `vehicleYear` - год выпуска
- `vehicleBrand` - марка
- `vehicleModel` - модель
- `vehicleModification` - модификация
- `vehicleColor` - цвет
- `vehicleData` - дополнительные данные в формате JSON (двигатель, тип кузова, коробка передач, привод)

### 2. Создана утилита для декодирования VIN
**Файл:** `src/lib/utils/vin-decoder.ts`

Функционал:
- Декодирование через NHTSA API (бесплатный API для автомобилей, продаваемых в США)
- Локальное декодирование по стандарту ISO 3779 (базовая информация: год, марка по WMI)
- Поддержка популярных марок автомобилей

### 3. Обновлен API endpoint
**Файл:** `src/routes/api/help-requests/+server.ts`

При создании запроса консультации:
1. Если указан VIN (17 символов) → автоматически декодируется
2. Декодированные данные сохраняются в БД
3. Если декодирование не удалось → запрос всё равно создается (без данных об автомобиле)

### 4. Обновлена админ-панель
**Файл:** `src/routes/admin/help-requests/+page.svelte`

При просмотре запроса консультации:
- Если VIN декодирован → показывается блок "Информация об автомобиле" с:
  - Год выпуска
  - Марка
  - Модель
  - Модификация
  - Цвет (с цветным индикатором)
  - Дополнительная информация (двигатель, тип кузова, коробка передач, привод)

## 📊 Как это работает:

### При отправке формы консультации:

1. Пользователь заполняет форму, указывает VIN (необязательно)
2. При отправке формы:
   - Если VIN указан и содержит 17 символов → автоматически декодируется
   - Декодирование происходит через NHTSA API (для американских авто) или локально (год + марка по WMI)
   - Декодированные данные сохраняются в БД вместе с запросом
3. Пользователь видит сообщение об успешной отправке

### При просмотре запроса в админке:

1. Менеджер открывает запрос консультации
2. Если VIN был декодирован → видит блок "Информация об автомобиле" с:
   - Год выпуска
   - Марка
   - Модель
   - Модификация
   - Цвет (с визуальным индикатором)
   - Дополнительные характеристики (если доступны)

## 🔍 Примеры VIN для тестирования:

- **Volkswagen**: `WVWZZZ1KZAW123456`
- **BMW**: `WBA3A5G59CNP84845`
- **Toyota**: `JTMHV05J504123456`
- **Tesla**: `5YJ3E1EB8KF123456`

## ⚠️ Ограничения:

1. **NHTSA API** - работает только для автомобилей, продаваемых в США
2. **Локальное декодирование** - дает базовую информацию (год, марка по WMI)
3. **Для российских авто** - требуется интеграция с российскими API (avtobot.org, Автопроверка и т.д.), для которых нужен API ключ
