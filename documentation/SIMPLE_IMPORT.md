# ⚡ Простой импорт - Одна команда

## Запуск

```bash
docker compose exec app node scripts/fix-and-import.js
```

**Всё!** Скрипт автоматически:
1. ✅ Исправит пользователя MySQL (если нужно)
2. ✅ Импортирует все 4000+ строк из CSV
3. ✅ Покажет прогресс и статистику

## Настройка паролей (если нужно)

Если пароли не совпадают, откройте `scripts/fix-and-import.js` и измените строки 12-13:

```javascript
mysql: {
  rootPassword: 'ВАШ_ROOT_ПАРОЛЬ',    // ⬅️ Измените
  password: 'ВАШ_ПАРОЛЬ_ПОЛЬЗОВАТЕЛЯ', // ⬅️ Измените
  // ...
}
```

**Где взять пароли?**
- Посмотрите в файле `.env` на сервере
- Или используйте текущие (уже указаны в скрипте)

## Проверка после импорта

```bash
# Проверить количество товаров
curl http://localhost:3000/api/health
```

Должно вернуть JSON с `partsCount > 0`.
