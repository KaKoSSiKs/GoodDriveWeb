# 🔧 Исправление ошибки: Cannot read properties of undefined (reading 'create')

## ⚠️ Проблема

Ошибка `Cannot read properties of undefined (reading 'create')` означает, что Prisma Client не знает о модели `HelpRequest`.

**Причина:** Dev сервер загрузил старую версию Prisma Client до добавления модели `HelpRequest` в `schema.prisma`.

## ✅ Решение

### Шаг 1: Остановите dev сервер
Нажмите `Ctrl+C` в терминале, где запущен `npm run dev`

### Шаг 2: Выполните генерацию Prisma Client
```bash
npx prisma generate
```

### Шаг 3: Перезапустите dev сервер
```bash
npm run dev
```

## ✅ После этого:

1. ✅ Форма консультации заработает
2. ✅ Запросы будут сохраняться в БД
3. ✅ Ошибка исчезнет

## 🔍 Проверка

После перезапуска сервера:
1. Откройте форму консультации на главной странице
2. Заполните и отправьте форму
3. Должно появиться: "Ваша заявка отправлена. Специалист свяжется с вами в ближайшее время."
4. В админ-панели → "Запросы" должен появиться запрос

---

**Важно:** Dev сервер должен быть остановлен перед выполнением `npx prisma generate`, иначе файлы Prisma Client будут заблокированы.
